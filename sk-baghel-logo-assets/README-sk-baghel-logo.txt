AGRA SK BAGHEL TOUR & TRAVELS — LOGO ASSETS

Files
- sk-baghel-logo.svg: primary horizontal logo for light backgrounds. The wordmark reads “AGRA SK BAGHEL TOUR & TRAVELS”.
- sk-baghel-logo-inverse.svg: inverse horizontal logo for dark backgrounds.
- sk-baghel-mark.svg: standalone SK mark; use for favicon/app icon or very compact placements.

These files are clean vector SVGs with no embedded raster images. The SK BAGHEL lettering is converted to vector paths; the new AGRA prefix uses the SVG font stack Montserrat, Inter, Arial, sans-serif.

Suggested placement in a React/Next.js project
1. Copy the SVG files into `public/assets/brand/` as `agra-sk-baghel-logo.svg`, `agra-sk-baghel-logo-inverse.svg`, and `agra-sk-baghel-mark.svg`.
2. Use the primary logo for the header and footer on light surfaces:
   <img src="/assets/brand/agra-sk-baghel-logo.svg" alt="Agra SK Baghel Tour & Travels" width="250" height="77" />
3. Use sk-baghel-logo-inverse.svg on dark surfaces.
4. Use sk-baghel-mark.svg for compact placements. For favicons, add a favicon SVG link in the document head and test it in target browsers.
5. Do not stretch the logo. Keep width auto/height auto or preserve its aspect ratio.
